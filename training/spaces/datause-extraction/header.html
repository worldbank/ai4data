Small AI demo

Data-use extraction

Find the datasets a passage mentions, then read how each named dataset is used: its producer, year, geography, type and role in the analysis. Two small fine-tuned models, loaded and ready, run on a shared GPU.

Demo only. Your text is not stored. It is processed on this Space's server, on a shared GPU, and the app does not store it or send it to any other service.

Step 1 · finds mentions gliner_agents_v3 GLiNER rafmacalaba/gliner_agents_v3 Fine-tuned for the program from urchade/gliner_large-v2.1. Task Marks each data mention in the passage and types it. Labels NAMED_DATA (a specific source by name or acronym), DESCRIPTIVE_DATA (described, not named), VAGUE_DATA (generic wording). Holdout 2,108 passages. At threshold 0.6, precision 0.92 and recall 0.76. Model card
Step 2 · reads each named mention lfm2.5-350M-focus-metadata 350M parameters rafmacalaba/lfm2.5-350M-focus-metadata Fine-tuned for the program from LiquidAI/LFM2.5-350M (LoRA, merged). Task Given the passage and one named mention, answers two tasks as JSON. Attributes Theme tags, geography, year, version, producer, acronym and data type. Values must appear in the passage. Usage Role (primary, supporting, background), usage action (source, analyze, curate, validate, inform) and a one-sentence summary. Holdout 2,160 rows scored against agent annotations, not human gold. Valid JSON in every row; usage action accuracy 0.59. Model card
