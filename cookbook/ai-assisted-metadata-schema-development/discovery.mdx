# 2. Metadata Discovery

**Question:** How can descriptive requirements emerge independently from artifacts?

:::note[Structural draft]
This chapter establishes learning milestones and candidate recipes. Detailed
procedures, worked examples, executable exercises, and implementation checks
remain for later authoring. Intended results below describe planned recipes.
:::

## Rationale

A metadata observation proposes a reusable descriptive property and records the evidence that motivated it. Its field name and observed value serve different purposes. Discovery explores potential requirements before a shared vocabulary is fixed.

Independent assessment lets each artifact contribute without inheriting the names chosen for earlier artifacts. Repetition, ambiguity, and candidates later excluded from the schema remain evidence for subsequent review.

## Target state

- Each observation retains its artifact identity, proposed field, observed value, source level, description, and rationale.
- Discovery requests remain independent of an evolving shared inventory.
- Uncertainty and failed or incomplete responses remain visible.

## Learning objectives

- Separate field names from artifact-specific values.
- Interpret source levels and explain how collection processing preserves independent requests and execution evidence.

## Prerequisite concepts

Chapter 1 establishes artifact identities and scope. The practitioner understands structured API responses and the difference between artifact evidence and document context.

## Maturity levels

| Level | Steps |
|---|---|
| **Foundational** | Inspect retained observations and source artifacts with a reviewer. |
| **AI-ready** | Define observation records with identities, evidence sources, and execution status. |
| **AI-native** | Process independent model requests with recorded settings, response checks, and later human acceptance decisions. |

:::info[Running example]
The Jordan, Afghanistan, and Russia examples contain figure_title, table_title, and chart_title observations. The Russian figure has both a caption and an internal chart title with different wording. Pakistan and Lebanon observations preserve specialized and potentially excluded candidates. These outputs remain model hypotheses.
:::

## Common mistakes

- Observed categories can be mistaken for reusable field names.
- Early vocabulary reuse can suppress descriptive differences.
- A model observation can be mistaken for a human-verified annotation.
