# 3. Field Profiles and Metadata Concept Synthesis

**Question:** How do local observations become manageable evidence for shared concepts?

:::note[Structural draft]
This chapter establishes learning milestones and candidate recipes. Detailed
procedures, worked examples, executable exercises, and implementation checks
remain for later authoring. Intended results below describe planned recipes.
:::

## Rationale

Exact-name aggregation collects repeated observations into a metadata field profile. The profile summarizes accumulated values, descriptions, rationales, and occurrence patterns. This deterministic transformation preserves lexical differences for later reasoning.

Canonical metadata concept synthesis then compares meanings across profiles. It proposes shared concepts while retaining uncertain distinctions for human review. Candidate concepts provide a review space before operational fields are designed.

## Target state

- Profile counts reconcile with the contributing observations.
- Occurrence counts and distinct-snapshot support have explicit denominators.
- Candidate concepts retain definitions, representative fields, and synthesis rationales.

## Learning objectives

- Distinguish exact-name grouping from semantic consolidation.
- Interpret profile evidence and explain why uncertain concepts can remain separate.

## Prerequisite concepts

Chapter 2 establishes observation records. The practitioner understands counts, distinct identifiers, and the difference between a field name and its potential meaning.

## Maturity levels

| Level | Steps |
|---|---|
| **Foundational** | Compare repeated names with their values and descriptions. |
| **AI-ready** | Aggregate profiles deterministically and reconcile counts and provenance. |
| **AI-native** | Use bounded model synthesis to propose concepts with evidence and uncertain distinctions retained for review. |

:::info[Running example]
Three real geographic_scope observations support the prepared subset exercise. Its three-observation result is separate from the recorded 192-observation profile. The full study aggregated 3,041 observations into 833 profiles and synthesized 70 candidates. Title profiles supply the semantic-consolidation example.
:::

## Expected artifact

Field profiles and a candidate metadata concept inventory will provide the evidence for expert refinement.

## Implementation options

Ordinary table aggregation can produce profiles. Human comparison or bounded model assistance can synthesize concepts. Similarity analysis is an optional review aid whose value depends on inventory size.

## Common mistakes

- Semantic normalization during exact-name grouping can erase distinctions.
- Occurrence counts can be confused with distinct-snapshot support.
- Aggressive synthesis can remove a meaningful distinction before expert review.
