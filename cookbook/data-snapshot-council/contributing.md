# Contributing

Use the [cookbook authoring guide](/cookbook/authoring/) and its recipe template when proposing a change. A recipe should name a result, maturity level, skills, indicative time, and a verification step.

Report corrections through [GitHub issues](https://github.com/worldbank/ai4data/issues). Include the chapter, artifact, sample or rule ID where applicable, and the evidence for the correction.

Use verified crops with source attribution and review their reuse terms. Distinguish published human-reviewed metadata from illustrative round records. A proposal that changes an example artifact should update the manifest and related references. Claims about policy quality require independent measurements.
