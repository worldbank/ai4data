## Interpretation of the result

- Chapter 1 first: a purpose statement and a label take a day and prevent
  the misuse that makes synthetic data a risk.
- Chapters 3 and 4 before any release: a file nobody measured is a file
  nobody can vouch for.
- Chapter 7 is where the value appears; a measured file nobody is offered
  changes nothing.
